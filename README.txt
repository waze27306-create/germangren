--- Thank you for playing "Touch The Girl! ---
(Compatible Windows10 or later)

Thank you for playing "Touch The Girl!"
Run "touchthegirl.exe" to start the game.
Read the manual(manual_eng.html) for how to play the game and more detailes.

When updating Hard version, run "updater.exe" in "updater" folder.
The new files are automatically copied into the existing folder.
Please read "HOW2UPDATE.txt" for more details.

! -- Complete version(distributed only on Patreon) doesn't need
the updater. Always start the game in the newest package.

! -- When upgrading from Soft version(free demo) to Hard/Comp version,
start Hard/Comp version without updating Soft version.
The settings will be inherited, but the order list of the costumes
will be initialized.
So please reinstall the additional costume sets as needed.
("Costume settings" like color is not initialized.)
